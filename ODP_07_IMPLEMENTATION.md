# Текущее состояние ABI 0.7-redesign-7

На 2026-09-20 локальный контрактный кандидат содержит core и девять спутников. Текущие интерфейсы — `chain/abi/`; каталог `chain/generations.json` не содержит approvedGenerations.

- Profile stop удалён; getCreator — четыре поля. Нет admin pause, recovery, mint delegation, wallet rotation.
- Отзыв паспорта — отдельное необратимое право исходного issuer с ненулевой причиной: включительно до `mintTimestamp + 259200` для профиля C и до `mintTimestamp + 86400` для B/P/M, и только пока нет фиксации печати.
- `finalizePassportForPrint` необратимо закрывает окно отзыва; повтор — no-op; `getPassportReleaseState` возвращает дедлайн и момент фиксации. Ядро не наблюдает принтер; удержание экспорта на печать — обязанность приложения и здесь не реализовано.
- Любая неуникальная модель тиража (limited/open/dynamic), даже без unit-якорей, требует профиль B; иначе EC(121).
- Mint/journal/proof используют operationId; digest/replay/conflict не зависят от последующего lifecycle. Edition связывается typed commitment; открыть может исходный B issuer при nonrevoked passport, без profile-stop барьера.
- Reference tools выполняют strict UTF-8, semantic/address-list/tree checks, custom bit31, digest и statement validation. Безопасный ZIP и полная клиентская цепочка остаются открытыми.
- Фиксированный release, manifest/resume, nonce/spend limits, два RPC/finality и финальная сверка десяти контрактов реализованы в deployment tooling. Polygon mainnet выбран, Amoy не обязателен. Сейчас запрещены кошелёк, внешняя сеть, deployment и публикация.

[Зафиксированный пакет аудитору](review/audit-handoff-abi6/README.md) описывает прежнюю ABI `0.7-redesign-6` и текущие исходники не подтверждает. [Дельта кода и документации плюс локальные проверки](ODP_07_ABI6_DOCUMENTATION_DELTA.md) описывают выполненную после него работу и открытые противоречия. Ни подготовка пакета, ни локальные тесты не являются внешним аудитом, готовностью приложения или разрешением выдачи.

Закреплённого release-бандла для этих исходников нет: единственный имеющийся бандл относится к `0.7-redesign-6` и отвергается текущими deployment-скриптами. Подробности и требуемое решение — раздел 5.3 дельты.

Реализованы ядро и восемь сателлитов, подготовка/проверка документов, схема, эталонные векторы,
экспорт ABI, актуальные TypeChain, локальные тесты и безопасная процедура manifest для будущего развёртывания.
**Статус: локальный release candidate, подготовленный к независимому ревью и отдельному решению о deployment.**
Нет оснований называть программный код «идеальным» или отсутствие найденного exploit доказательством
отсутствия ошибок. Здесь отдельно фиксируются исполненные проверки и продуктовые ограничения.

[chain/generations.json](chain/generations.json) намеренно содержит пустой `approvedGenerations`.
Новый реестр не развёрнут в публичной сети. Существующие адреса0.6/старой0.7 не подставлены.
Сборка/тесты не читают `.env` реальных кошельков. Все экземпляры из тестов — локальные EDR.

это закрывает незаданную судьбу уже существующей функции (AST-14), не возвращает ядру внешнюю зависимость.
Добавлен выход ребёнка из связи. Создание требует активных сторон; удаление/отмена — доступная cleanup-операция.

## Что изменено в инструментах

`npm run compile` теперь падает при превышении EIP-170 или внешнем library link и экспортирует10 ABI.
Локальная EDR больше не использует allowUnlimitedContractSize. Нормализован недетерминированный порядок TypeChain exports/overloads: factory ABI/bytecode при этом не меняются. TypeChain нужно сохранять вместе с новым
кодом: первоначальный совет откатить `chain/types/` относился к **проверке старой базы**, а не к согласованной
переработке интерфейса. Здесь устаревшие factory заменяются результатом текущей сборки.

Старые freeze/resume/satellite-only/mint.py команды останавливаются с объяснением до работы с кошельком.
Новый deploy сохраняет manifest до broadcast и после каждой квитанции; исключает smoke-mint, library-link
и wiring. Он написан, но **не запускался**. Для реального запуска нужно отдельное разрешение пользователя.

## Сохранённые ограничения и условия реального выпуска

1. Это reviewable release candidate смарт-контрактов, не проведённое сторонней организацией окончательное
   security-заключение. Slither, тесты и модели не заменяют независимое ревью нового bytecode; Mythril/Echidna
   и формальное доказательство не выполнялись.
2. P/M permissionless, имена/домены/authorSigner сами по себе не доверие. Sybil/spam решаются клиентской
   политикой и независимыми источниками личности. Квотный календарь намеренно приблизительный.
3. 72ч измеряются block.timestamp. Активация может быть опубликована держателем клона раньше покупателя;
   мастер/печатник могли сохранить код. Нельзя доказать уничтожение копий секретов.
4. Сателлит не восстанавливает JSON из anchorsHash. Клиент обязан проверять документ, файлы, root/count/nonce/
   namespace и исторический адрес. Невозможность чтения не равна отсутствию замечаний или активации.
5. Loss/stopped issuer необратим; hosting нельзя обновлять после stop. После72ч нет core-revoke и встроенного
   replacement/issuer-event канала. Это принятые продуктовые свойства.
6. Мобильные приложения, ZIP-extraction, реальные NFC-теги, RPC/finality/reorg и публичный deployment не
   проверены этой работой. Offline-модули имеют явные границы проверки; прежние приложения надо адаптировать
   к новому ABI и receipt.json. Полный русский перевод новой SPEC пока заменён честным указателем на норму.
7. npm audit после совместимых обновлений не сообщает high/moderate; остаётся11 low в транзитивной цепочке
   elliptic/ethers-v5 tooling без доступного upstream fix. Сам runtime Solidity их не включает; новые
   офлайн-инструменты используют ethers6.17.0. Lockfile закреплён; автоматического force-major update не было.

Ни одна из этих границ не скрыта словом «идеальный». Готовность к реальному адресу подтверждается отдельно:
проверенный source/build identity → утверждённый manifest → разрешённый deploy → независимое сравнение runtime
и adoption клиентами. В этой сессии последние операции не выполнялись.

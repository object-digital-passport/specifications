# ODP v0.7.1 — clearer rules and guides

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

**A documentation and tooling pre-release for ODP 0.7.** It uses the existing registry on Polygon and the same passport file format.

## What changed

- The rules for formatting a passport file for verification are clearer. Thanks to [@tylrcc](https://github.com/object-digital-passport/specifications/pull/184) for clarifying which extra bytes to leave out.
- The English and Russian guides now link to the section on scanning an NFC seal from the contents, show file names correctly and cover the seal once. Thanks to [@kamrullab](https://github.com/object-digital-passport/specifications/pull/191) for proofreading both guides.
- The documentation explains how to tell whether a transaction from a shared Safe wallet reached the network and whether the passport operation succeeded.
- The project front page explains how ODP works and where to start. The deployment record links the live registry to its published source code.
- The command-line guide shows how to pass the registered issuer type for a production run. The test tools also received security updates.

## Do I need to do anything?

- **You already registered a passport** — keep verifying it against its original registry.
- **You are about to register one** — use a tool that supports the existing v0.7 registry and passport file format.
- **You run your own copy** — keep using the v0.7 addresses, contract interface and file format. Use this snapshot for the updated documentation and tools.

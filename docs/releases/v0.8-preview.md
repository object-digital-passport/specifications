# ODP v0.8 — object history and evidence

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

**Proposal preview.** These ideas are open for discussion. ODP 0.7 is the version you can use today.

## What changed

- **Give an object a history.** A repair shop could add a diagnosis to a used phone's passport, and a conservator could add a restoration report and photos to an artwork's passport. Readers could check who published each entry and whether its files match.
- **Connect to identifiers already used on products.** Explore how existing product codes, serial numbers, batch numbers and expiry dates could be shared with ODP.
- **Open a passport from a regular camera app.** Test the scan on iPhone and Android, and check how readers find the passport from the printed number if the issuer's website is unavailable.
- **Explore a medicine batch pilot in Bangladesh.** Study how buyers could see separate checks for the batch, its quality documents and any warnings. A scan alone cannot tell a buyer what is inside a pack.

## Do I need to do anything?

- **You already registered a passport** — keep verifying it against its original registry.
- **You are about to register one** — use a tool that supports the deployed v0.7 registry.
- **You run your own copy** — keep using the v0.7 addresses and file format for new passports.

# ODP v0.7 — a registry nobody can override

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

**Live on the Polygon network since 25 September 2026.** New passports go to this version. The ODP apps and the check page are being moved to it; until an app says it supports v0.7, it still issues on v0.6.

## What changed

- **Nobody holds special powers over the registry.** There is no administrator, no off switch and no owner field. A passport records one thing: this profile registered this description and these fingerprints of its files at this moment.
- **A mistake can be withdrawn only for a short time.** An individual maker has 72 hours after registering, and a brand, expert or museum has 24. Before a label goes to print, the issuer closes that window for good, so a printed label never points at a passport that can still be withdrawn.
- **One passport can cover a whole production run, and only brands can issue one.** Each item carries its own key under a scratch layer. Everyone else registers one-of-a-kind objects.
- **A photo can be shared without giving away the original.** The issuer can publish a lighter copy of the main photo, with no location data, and anyone can check it against the registry. The full-size original stays in the owner's passport file.
- **Your wallet is yours alone, and nobody can restore it.** A wallet is the app that holds the key you sign with. ODP apps never create one or store its key; you connect your own. A lost key cannot be recovered and a stolen one cannot be blocked, so keep the wallet's backup safe and never type its recovery words into any other app or page. Checking a passport never needs a wallet. Brands, experts and museums are advised to use a wallet that needs two of several people to sign, so one stolen key cannot act alone. A sponsor such as a university can pay network fees only by topping up your wallet; it gets no access to it.
- **Apps must warn before any step that cannot be undone,** such as registering, issuing, marking for print or withdrawing. Each issuer must publish its profile number where people can compare it. A QR code may lead to the issuer's own website and still be checked without it.

## Do I need to do anything?

- **You already registered a passport** — nothing. Records on earlier registries stay readable, and the check page still finds them. They do not move to this version.
- **You are about to register one** — use this version once your app supports it. Prepare a wallet you control and back it up before your first passport.
- **You run your own copy** — this is a new set of contracts, not an upgrade of v0.6, so anything built against it must be rebuilt. Point your pages at the new addresses.

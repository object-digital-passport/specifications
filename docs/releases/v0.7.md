# ODP v0.7 — a registry nobody can override

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

**DRAFT, not for publishing: nothing is deployed yet.** After the Polygon mainnet deployment, replace every `YYYY-MM-DD` and `0xADDRESS` below, check the sentence about the audit under Status, and rewrite this paragraph as "Live on the Polygon network since …". Until then there is no v0.7 registry on any network, and new passports still go to v0.6. The August 2026 v0.7 preview was a published design, never deployed, and this version replaces it.

## What changed

- **Nobody holds special powers over the registry.** There is no administrator, no off switch and no owner field. A passport records one thing: this profile registered this description and these fingerprints of its files at this moment. The flip side, said plainly: a lost key cannot be recovered, and a stolen one cannot be blocked. ODP cannot step in either way.
- **A mistake can be withdrawn only for a short time.** An individual maker has 72 hours after registering to withdraw a passport, and a brand, expert or museum has 24. Before a label goes to print, the issuer closes that window for good, so a printed label never points at a passport that can still be withdrawn. After that, a correction means a new passport plus a public note explaining why.
- **One passport can cover a whole production run, and only brands can issue one.** Each item carries its own key under a scratch layer. Everyone else can register only one-of-a-kind objects.
- **A photo can be shared without giving away the original.** The issuer can publish a lighter copy of the main photo, with no location data, and anyone can check it against the registry. The full-size original stays in the owner's passport file.
- **Apps must warn before any step that cannot be undone,** such as registering, issuing, marking for print or withdrawing. A QR code may lead to the issuer's own website and still be checked without it. A sponsor such as a university can cover network fees only by topping up a user's wallet.

## Do I need to do anything?

- **You already registered a passport** — nothing. Records on earlier registries stay readable, and the check page still finds them. They do not move to this version.
- **You are about to register one** — use this version. It is where new passports go.
- **You run your own copy** — this is a new set of contracts, not an upgrade of v0.6 or of the v0.7 preview, so anything built against either must be rebuilt. Point your pages at the new addresses.

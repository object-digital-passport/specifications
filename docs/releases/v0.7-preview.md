# ODP v0.7 — passports for things made in thousands

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

**This is a pre-release, and nothing is deployed.** No v0.7 registry exists on any network, so you cannot register anything against it yet. It is published so the design can be read and argued with before it is set in a contract.

## What changed

- **One passport can now cover a whole production run.** A brand making 100 000 identical figures registers the edition once, and each box carries its own key under a scratch layer. Registering the run costs the same as registering one object.
- **Scratching a code leaves a permanent public mark.** Anyone can then see that this particular item was opened, and when — so a second buyer of the same code learns something a brand's private database would never have told them.
- **A blind box can prove what was inside it** without spoiling the surprise beforehand, which makes a rare figure's rarity checkable instead of a seller's claim.
- **Nothing printed on an object names a website any more.** The code carries the passport's identifier and nothing else — an address on a label is a promise about a server that outlives the server.
- **The example website moved out** to [its own repository](https://github.com/object-digital-passport/object-digital-passport.github.io). This repository is the standard, the contracts, and the tests that check them.

## Do I need to do anything?

- **You already registered a passport** — nothing. Earlier registries are untouched and still verify. Old website addresses redirect on their own.
- **You are about to register one** — use v0.6. This line has no registry yet.
- **You run your own copy** — nothing yet. When v0.7 is deployed it will be a new registry, not an upgrade of v0.6.

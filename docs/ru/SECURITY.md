# Безопасность ODP 0.7 — ABI 0.7-redesign-7

Английская [SPEC](../../SPEC.md) нормативна; эта страница передаёт [модель безопасности](../SECURITY.md).
[Запечатанный пакет ABI6](../../review/audit-handoff-abi6/README.md) и [дельта документации](../../ODP_07_ABI6_DOCUMENTATION_DELTA.md) разделяют старые и новые свидетельства.

| Область | Обеспечивается | Не устанавливается |
|---|---|---|
| Core | Прямой issuer mint, immutable поля, operation replay/conflict, отзыв C до72h / B/P/M до24h и только до фиксации печати | Истинность, собственность, подлинность, восстановление ключа |
| Профили P/M | Постоянная регистрация кошелька и выбранного типа | Аккредитация; регистрация открыта |
| Concerns | Один активный эпизод на пару, собственный withdrawal, стабильные индексы | Голосование, консенсус или вердикт |
| Hosting | Отдельное разрешение агенту с исключительной границей expiry | Безопасность URL, доступность и правильность файлов |
| Author signature | EIP-712 bytes/domain и владение ключом | Личность произвольно выбранного issuer ключа authorSigner |
| Edition | Core commitment, уникальность issuer nonce, Merkle membership, подпись, одноразовая активация | Владение вещью, момент покупки или достоверное обнаружение копии |
| Journal | Роли, собственный lifecycle, атомарная замена predecessor и withdrawal | Истинность, личность и доступность payload |
| Directory | Синтаксис самозаявленного DNS имени | Контроль домена или статус организации |
| Generation pins | Внешняя политика клиента | Администратор core её не обеспечивает |

Profile stop удалён полностью: нет revokeCreator, CreatorRevoked, профильного revokedAt, admin pause, ротации или key recovery. getCreator возвращает четыре поля. Компрометированный ключ сохраняет issuer-права. Нет mint-agent; publishing agent имеет только отдельное разрешение хостинга.

Фиксация печати (`finalizePassportForPrint`) необратима и досрочно закрывает окно отзыва. Это только отметка в реестре: ядро не наблюдает принтер, не предотвращает внешнюю печать, а печатный шлюз приложения в этом репозитории не реализован. Компрометированный ключ может зафиксировать паспорт и тем закрыть собственное окно исправления законного издателя.

Отзыв паспорта — отдельное право исходного issuer, однократно при `now <= mintTimestamp + 259200` для C / `+ 86400` для B/P/M, только до фиксации печати, с ненулевым reasonHash. Passport revokedAt остаётся. Отзыв необратим, не стирает payload/историю и не выносит вердикт о подделке. Immutable lifecycleStatus — классификация при выпуске; revoked и состояния заявлений изменяются по своим правилам.

Solidity не читает JSON/оригиналы и не восстанавливает ключи, скрытые коды или файлы из hashes. Клиент отдельно проверяет байты, карточку, namespace/root/nonce и личность. Подпись произвольного authorSigner не устанавливает личность автора; issuer может занять one-shot слот своим ключом. Withdrawal не освобождает слот. Независимые заявления используют journal.

Ядро не вызывает внешний код; спутники закрепляют core и не могут присвоить права в нём. Новый спутник — другое пространство истории. Клиент сохраняет адрес активаций из исходного тиража; version byte 7 недостаточен для decoder. Нужны chain/address/runtime/ABI и согласованный блок.

Mint/journal/proof operationId действует для caller в выбранном контракте. Перед восстановлением результата сверяются полный digest, namespace, receipt и finality. Exact replay после withdrawal/supersession/revoke/смены месяца возвращает исходную запись через custom error и не оживляет её. Отсутствующий результат на блоке не доказывает отсутствие pending отправки.

Reference tools реализуют strict UTF-8, custom bit31, полный address-list/tree и statement validation. Безопасный ZIP, защита URL fetch/redirect/private-IP, client finality и identity UI требуют отдельной приёмки. Offline целостность не доказывает текущее сетевое состояние.

Локальные тесты включают отрицательные проверки прав, точные границы 72/24 часа, квоты, concern lifecycle, Merkle mutations, domains и document-to-EVM roundtrips. Они ограничивают известные риски, но не доказывают отсутствие ошибок и не заменяют независимый аудит.

Цель — Polygon mainnet без обязательного Amoy. Production generation не утверждена. Release/manifest/resume, nonce/spend limits и два RPC/finality уменьшают операционные риски, но не доказывают честность RPC. Сейчас запрещены кошелёк, внешняя сеть, deployment и публикация.

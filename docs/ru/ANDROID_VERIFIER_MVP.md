# Android-верификатор, MVP (область)

*Перевод справочно. Нормативный оригинал — только на английском: [`docs/ANDROID_VERIFIER_MVP.md`](../ANDROID_VERIFIER_MVP.md). Этот текст может содержать ошибки; при расхождении верен английский.*

Минимально полезный отдельный верификатор для **ODP + NTAG 424 DNA TagTamper**: рантайм NFC, раздельные строки доверия (носитель, офлайн-нагрузка, сессия чипа, привязка `nfcPublicKey`, канонический `dataHash`) — не превращаясь при этом в полноценное рабочее место эмитента.

> **Статус: эта область так и не была реализована.** Android-верификатор, который здесь описан,
> начали и забросили; публичной реализации якоря `nfc` нет ни на одной платформе. Эталонная
> реализация сейчас разрабатывается как приложение ODP для iOS — см.
> [GUIDE.md](GUIDE.md#как-читают-nfc-пломбу). Документ сохранён потому, что граница области,
> которую он проводит, по-прежнему верна, и следующая попытка должна начинаться с неё.

**Интеграция:** [docs/ANDROID.md](https://github.com/object-digital-passport/object-digital-passport.github.io/blob/main/docs/ANDROID.md) · **пилот по чипу:** [ANDROID_NTAG424DNA_TAGTAMPER.md](ANDROID_NTAG424DNA_TAGTAMPER.md).

Браузер уже проверяет реестр и `dataHash`, но он не может выполнить EV2 или прочитать TagTamper. TagWriter пишет только носители; Tag TrustLink умеет аутентифицировать чип, но не привязать его к паспорту ODP без сравнения с `nfcPublicKey` в цепи.

Полный список требований (строки результата, правила хэширования NDPP, граница MVP) — в историческом развёрнутом черновике в истории git или в разделах про модель доверия в README компаньона.

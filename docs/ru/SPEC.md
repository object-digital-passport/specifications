# Спецификация ODP 0.7

Для переработанного поколения **`0.7-redesign-7` нормативна [SPEC.md на английском](../../SPEC.md)**.
Прежний полный русский перевод относится к старому ABI и сохранён в
[архиве](../../review/astra/legacy-docs/docs/ru/SPEC.md). Его нельзя использовать для интеграции нового ядра.

Текущее русское описание изменений, проверок и оставшихся границ выпуска:
[этап контрактов и проверок](../../review/v07-stage4/README.md).
Независимая проверка предшествующего аудита: [ODP_ASTRA_REVIEW.md](../../ODP_ASTRA_REVIEW.md).

Ключевые правила: неизменяемая карточка, отсутствие владельца/transfer/governance, отзыв исходным издателем
включительно до72 часов для профиля C и до24 часов для B/P/M и только до необратимой фиксации печати,
отдельные права выпуска и хостинга, `passportId: null` в хешируемом документе,
nonce вместо будущего ID при подготовке тиража, постоянный адрес сателлита активаций в его anchor.
Эта страница — указатель на новую норму, не заявление о завершённом полном переводе.

# Object Digital Passport

Открытый реестр заявлений издателя и неизменяемых хешей документов о физических, цифровых и смешанных
объектах. Реестр фиксирует, какой кошелёк зарегистрировал данные и когда. Он не устанавливает владение,
подлинность или личность автора: это отдельные проверки.

## Локальная проверка

Нужны Node22.10+ и npm:

```sh
cd chain
npm ci
npx hardhat clean
npm run check
```

Команда компилирует Solidity0.8.20, проверяет лимит размера EVM, векторы и тесты в локальной EDR.
Сборка и тесты не читают файлы настоящих кошельков. `chain/types/` соответствует текущему ABI;
CI проверяет отсутствие изменений после повторной сборки.

## Границы контрактов

В ядре остались неотзываемая регистрация профиля, неизменяемые карточки/хеши, выпуск от собственного кошелька и отзыв в первые72 часа для C /24 часа для B/P/M, только до необратимой фиксации печати. Администратора, freeze, владельца, transfer, изменяемого
поля lifecycleStatus, API общей истории событий паспорта, URL, router и unit-passport нет. Библиотека встроена в код ядра.

Девять независимых сателлитов хранят замечания, адреса файлов, доменные заявления, экспертизы, подписи
автора, хеши документов кошелька, связи организаций, журнал утверждений и активации тиража. Они не изменяют ядро.
Ключи тиража выводятся из заранее выбранного nonce. Адрес активаций закрепляется в документе навсегда;
смена сателлита по умолчанию не должна скрывать прежнюю историю.

## История проверки

Исходные150 тестов воспроизводили прежнее поведение; с независимыми контрпримерами было165.
Они сохранены вместе с исходными контрактами в `review/astra/`. Новые тесты проверяют другую модель,
поэтому сравнивать только их число некорректно. Прежние документы аудита и инструкции — исторический
материал. Для этой реализации действуют SPEC и новый ABI. Старые демо не являются развёртыванием этой
переработки. Интеграция Apple/Android требует отдельной проверки и выпуска.

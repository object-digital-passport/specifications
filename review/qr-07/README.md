# ODP 0.7: тест компактного QR

Это экспериментальные коды, **не** утверждённая грамматика ODP, не существующие паспорта, не ссылки на развёрнутые контракты. `07R1` — условное обозначение контекста именно этого эксперимента; версия `0.7` сама по себе недостаточна для различения старого и нового ABI. Сопоставление короткого контекста с полными адресами требуется независимо зафиксировать перед выпуском.

- `compact.png`: 32 ASCII bytes; специализированный ODP-reader; обычная камера не обязана предлагать открыть такую строку.
- `web.png`: 52 ASCII bytes; https://example.invalid — намеренно неработающий тестовый домен. Это образец нагрузки, не работающий resolver. Итоговый домен/путь может изменить размер QR.
- Q error correction; обязательная белая рамка 4 модуля с каждой стороны.
- `print-sheet.svg`: 12/15/18/20 mm, размер включает белую рамку. Печатать в 100% масштабе, проверить линейку 50 mm.
- `metrics.json`: измеренные размеры матрицы и расчёт размера модуля. Это не проверка реальной печати, камеры, бликов или повреждения скретч-покрытия.
- `generate.py`: воспроизведение через ReportLab/Pillow; `decode.swift`: независимое чтение через Apple Vision.

Коды не содержат секретов. Полная этикетка со скрытым кодом/скретчем ещё требует проектирования: эти SVG измеряют только QR и не доказывают, что вся этикетка помещается в такой квадрат. Нельзя обрезать белую рамку. Размер наклейки не объявляется утверждённым до испытаний физической печати и реального сканирования.

## Результат текущей проверки

Генерация выполнена; размеры матриц сохранены в metrics.json. Независимое декодирование в этой среде **не подтверждено**: Apple Vision (включая CPU-only) завершился ошибкой инициализации inference model; CoreImage также не завершил проверку успешно. Логи сохранены. Проверку физической печати/смартфоном не проводили. Эти ограничения не означают ни доказанную читаемость, ни доказанный дефект QR.

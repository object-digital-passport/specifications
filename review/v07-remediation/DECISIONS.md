# Решения и границы redesign-5

Дата: 2026-09-18. Протокол0.7, ABI `0.7-redesign-5`. Это локальный кандидат, не утверждение выпуска.

- D1 реализовано: обязательный operationId для journal/proof. Старые selectors не поддерживаются.
  Явное поручение пользователя «Приступай к починке» разрешило исправление production-кода после аудита.
- D2 не изменено: stop блокирует новое действие и revokePassport; собственные withdrawals доступны.
  Пользователю предложен выбор. Пока ответа нет, текущие права сохранены; это не принятое пользователем
  решение об остаточном риске. Stop не является полноценным механизмом восстановления украденного ключа.
- D3 текущие права сохранены: openEdition требует активного оригинального issuer. Workflow обязан
  завершить открытие до stop и сохранять данные для восстановления. Не вводилась новая привилегия.
- D4 компилятор0.8.20 сохранён для сопоставимости. Получен точный release bundle и воспроизводимость;
  это не закрывает review известных compiler bugs и не выбирает целевую сеть/финальность.
- Требование confirmations теперь обязательно в deployment. Значение для публичной сети пользователь
  ещё не выбирал. В локальных EVM-тестах используется1, это не рекомендация для публичной сети.
- Производственные QR/wire formats, изготовление/хранение секретов и независимый второй decoder
  остаются до выпуска физических носителей. Секреты/ключи в отчёт не добавлялись.
- Результат одноразового author attestation не подтверждает личность без независимой привязки ключа.
  Это уточнение NatSpec; права issuer выбирать ключ и один раз занимать слот не изменялись.
- Apple-приложение в этом checkout не изменено. Новый ABI, durable operation jobs, ZIP/URL security,
  chain/finality/history и round-trip остаются обязательной интеграцией согласно app handoff.
- Развёртывание в публичную сеть и публикация не разрешены и не выполнялись. Все deployments в логах
  используют локальную Hardhat EVM и тестовые аккаунты. Approved generations остаётся пустым.

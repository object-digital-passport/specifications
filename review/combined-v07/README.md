# Объединение аудитов ODP 0.7

[План исправлений](../../ODP_07_CONSOLIDATED_REMEDIATION_PLAN.md) содержит14 пунктов, решения до ABI freeze, этапы и критерии готовности.

`sources/` — неизменённые копии полученных отчётов, происхождение и SHA256 — `sources.json`. Их внутренние относительные ссылки относятся к исходным аудитным папкам; недостающие PoC Opus не включены. `reconciliation.json` фиксирует свежую сверку реализации и runtime. `check-anchor-mask.mjs` воспроизводил исходное неверное поведение F-08; зелёный запуск означает воспроизведение дефекта, а не исправление.

На этапе объединения создавались только документы и reproducer. После исправления F-08 старый reproducer ожидаемо завершается ошибкой: это историческое доказательство, а не regression test. Актуальные проверки и изменения — в [remediation](../v07-remediation/README.md).
